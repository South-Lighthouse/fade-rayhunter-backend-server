{% comment %} Renders a Leaflet map of `coverage_points` (a list of [lat, lon] pairs, blue dots, from dashboard.coverage.coverage_points_for -- already deduplicated to ~111m grid cells, so this never has to handle more than a few thousand points) and, optionally, `alert_points` (a list of [lat, lon, popup_html] triples, red markers, from dashboard.alerts.alert_points_for -- individual Rayhunter-flagged detections, never deduplicated since each is a specific event worth seeing on its own; the set stays small by construction). `map_id` must be unique on the page if included more than once. Basemap tiles come from Esri's free World Street Map service, not OSM's own tile servers, CartoDB, or Wikimedia: OSM's tile usage policy blocks direct app use (confirmed -- got a 403 "Access blocked" response), CartoDB's basemaps now require an API key (confirmed -- "API key required" watermark), and Wikimedia's tile server turned out to be restricted to Wikimedia's own properties (confirmed -- 403 on every real tile, the one earlier success was a stale cached edge hit, not genuine access). Esri's basemap tiles (server.arcgisonline.com) are free, require no key, and are a long-standing, widely used pattern for exactly this kind of embedding -- verified across zoom levels 5-19. Attribution still credits OSM/Esri per their terms. {% endcomment %}
